# 프로젝트 설명
- 이번 프로젝트는 지난 프로젝트의 간소화버전입니다. GCP 결제 가능 계정의 부재로 인해 따로 간소화 된 모델로 만들어 졸업작품전시회에 참여를 하게 되었습니다.

# 기능
- Vertax AI -> yolo, pytorch를 사용하게 되었습니다.
- Iaas -> local 클라우드 형태의 배포서비스를 로컬로 전환하였습니다.
- Pubsub Dataflow -> Apple Sidecar 카메라 기능을 대체하였습니다.
- RPI신호등 -> Arduino신호등으로 대체하였습니다.
- web page -> 이전 웹페이지보다 많은것을 보여주지 못한다는 문제가 있어 새로 만들게 되었습니다.
- 다른 기능들은 Main branch와 유사합니다.
